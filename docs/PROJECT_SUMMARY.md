# 轨道线路图设计器 - 项目概览

## 版本信息

**当前版本**: v1.1.0  
**发布日期**: 2026-02

## 产品定位

这是一个专为小朋友设计的地铁线路图创作工具，支持多种城市风格，可自由绘制线路、添加站点，并运行列车模拟。

### 核心功能模块

| 模块 | 功能 | 实现方式 |
|------|------|----------|
| 项目管理 | 创建/导入/导出项目 | JSON文件存储，Zustand持久化 |
| 线路管理 | 创建/删除/编辑线路 | 唯一性验证（名称+颜色） |
| 站点管理 | 添加/移动/删除站点 | SVG渲染，拖拽交互 |
| 轨道建设 | 直线/折线轨道 | 路径点计算，多轨道变细显示 |
| 终点站设置 | 智能识别/手动选择 | 基于连接数的端点检测算法 |
| 列车模拟 | 沿轨道运行/往返 | Canvas动画，路径插值计算 |
| 线路总览 | 站点列表/高亮显示 | 独立Tab，透明度控制 |
| 任务系统 | 渐进式任务引导 | 操作监听，自动检测完成 |
| 成就系统 | 成就解锁/奖励 | 条件检测，本地存储 |

## 数据模型

### 核心类型
```typescript
interface DesignProject {
  id: string;
  name: string;
  lines: Line[];
  stations: Station[];
  mapType: MapType;
  createdAt: string;
  updatedAt: string;
}

interface Line {
  id: string;
  name: string;          // 唯一
  color: string;         // 唯一
  stations: string[];    // 站点ID列表
  paths: LinePath[];     // 轨道路径
  startTerminus?: string;
  endTerminus?: string;
  isLoop: boolean;
  style: LineStyle;
}

interface Station {
  id: string;
  name: string;          // 全局唯一
  position: Position;
  isTransfer: boolean;
  lines: string[];       // 所属线路ID列表
}

interface LinePath {
  id: string;
  points: Position[];    // 路径点序列
}
```

## 约束规则

1. **线路名称唯一**：同一项目中不能有重名线路
2. **线路颜色唯一**：同一项目中不能有相同颜色的线路
3. **站点名称唯一**：站点名称在整个项目中唯一
4. **轨道唯一性**：同一线路两站点间只能有一条轨道
5. **级联删除**：删除站点时自动删除相连轨道
