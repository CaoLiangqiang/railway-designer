# 轨道线路图设计器 - 需求文档

## 1. 项目概述

### 1.1 项目背景
为儿童设计的地铁线路图创作工具，通过直观的拖拽操作和丰富的视觉反馈，帮助儿童理解城市轨道交通系统的基本构成。

### 1.2 目标用户
- 主要用户：6-12岁儿童
- 次要用户：家长、教师

### 1.3 项目目标
- 提供简单易用的地铁线路图设计工具
- 通过游戏化元素（任务、成就）增加趣味性
- 支持多种城市地铁风格，增加教育意义

## 2. 功能需求

### 2.1 核心功能

#### 2.1.1 项目管理
- [x] 创建新项目
- [x] 选择城市风格（上海、北京、广州、港铁、东京等）
- [x] 导出项目为JSON文件
- [x] 导入JSON项目文件

#### 2.1.2 线路管理
- [x] 创建多条线路
- [x] 线路名称唯一性校验
- [x] 设置线路颜色
- [x] 删除线路
- [x] 设置终点站（支持往返线和环线）

#### 2.1.3 站点管理
- [x] 添加普通站点
- [x] 添加换乘站点
- [x] 站点名称全局唯一性校验
- [x] 站点可属于多条线路
- [x] 拖拽移动站点位置
- [x] 删除站点（同时删除相连轨道）

#### 2.1.4 轨道管理
- [x] 建设轨道（选择起点、终点、所属线路）
- [x] 同一线路两站点间只能有一条轨道
- [x] 支持三种轨道形状：直线、一次折线、两次折线
- [x] 选中轨道后可切换形状
- [x] 删除轨道
- [x] 多条轨道时自动调整线条粗细

#### 2.1.5 自动连接功能
- [x] 添加站点时可选择是否自动连接至前一站点
- [x] 自动连接时创建路径，站点加入线路
- [x] 不自动连接时创建孤立站点

#### 2.1.6 列车模拟
- [x] 启动/停止列车模拟
- [x] 列车沿线路自动运行
- [x] 支持往返线和环线运行模式

### 2.2 任务系统

#### 2.2.1 任务列表
1. **初识线路**：创建包含3个站点的线路
2. **设置终点站**：为线路设置起点和终点站
3. **运行模拟**：成功运行列车模拟
4. **换乘枢纽**：创建一个换乘站
5. **环线设计**：创建一条环线
6. **多线路运营**：创建3条线路

#### 2.2.2 任务机制
- 自动检测任务完成状态
- 完成任务后显示完成提示
- 完成任务解锁奖励（新的城市风格）

### 2.3 成就系统

#### 2.3.1 成就列表
1. **设计新手**：创建第一个站点
2. **轨道工程师**：创建第一条线路
3. **换乘专家**：创建3个换乘站
4. **环线大师**：创建一条环线
5. **多线路运营**：创建3条线路
6. **模拟运行**：运行列车模拟
7. **城市设计师**：解锁所有城市风格
8. **终点站规划师**：为线路设置终点站

#### 2.3.2 成就机制
- 在关键操作时自动检测成就条件
- 解锁成就时显示提示

### 2.4 城市风格

#### 2.4.1 默认解锁
- 上海地铁风格
- 北京地铁风格

#### 2.4.2 任务解锁
- 广州地铁风格
- 港铁风格
- 东京地铁风格

## 3. 非功能需求

### 3.1 性能需求
- 页面加载时间 < 3秒
- 拖拽操作响应时间 < 100ms
- 支持同时显示50+站点和轨道

### 3.2 兼容性需求
- 支持 Chrome、Firefox、Edge、Safari 浏览器
- 支持 Windows、macOS、Linux 桌面应用

### 3.3 可用性需求
- 界面简洁，适合儿童使用
- 操作反馈明确
- 提供快捷键支持

### 3.4 数据持久化
- 自动保存到本地存储
- 支持导出/导入项目文件

## 4. 界面需求

### 4.1 布局
- 左侧：工具栏（线路、站点、操作）
- 中间：设计画布
- 右侧：任务面板

### 4.2 交互
- 鼠标点击放置站点
- 拖拽移动站点
- 滚轮缩放画布
- 中键拖拽平移画布

### 4.3 视觉
- 明亮友好的配色
- 清晰可辨的站点图标
- 不同线路使用不同颜色

## 5. 数据约束

### 5.1 唯一性约束
- 项目名称：无限制（不同项目可同名）
- 线路名称：项目内唯一
- 站点名称：项目内唯一
- 轨道：同一线路两站点间唯一

### 5.2 完整性约束
- 线路必须至少有一个站点才能运行模拟
- 轨道必须连接两个存在的站点
- 删除站点时同时删除相连轨道
- 不会出现两端没有站点的轨道

## 6. 快捷键

| 按键 | 功能 |
|------|------|
| Delete / Backspace | 删除选中的站点或轨道 |
| Esc | 取消选择 |
| 滚轮 | 缩放画布 |
| 鼠标中键拖拽 | 平移画布 |
