# 轨道线路图设计器 - 需求文档

## 版本: v1.1.0

## 1. 产品概述

### 1.1 产品定位
一个专为小朋友设计的地铁线路图创作工具，支持多种城市风格，可自由绘制线路、添加站点，并运行列车模拟。

### 1.2 目标用户
- 主要用户：6-12岁的小朋友
- 次要用户：家长（协助使用）

### 1.3 核心价值
- 激发创造力和想象力
- 学习地铁线路规划知识
- 培养空间思维能力
- 寓教于乐的互动体验

## 2. 功能需求

### 2.1 项目管理
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 创建项目 | 输入名称，选择城市风格 | P0 |
| 导入项目 | 从JSON文件导入 | P1 |
| 导出项目 | 导出为JSON文件 | P1 |
| 自动保存 | 本地存储持久化 | P1 |

### 2.2 线路管理
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 创建线路 | 输入名称和颜色（唯一性验证） | P0 |
| 删除线路 | 删除选中线路 | P0 |
| 选择线路 | 切换当前编辑线路 | P0 |
| 城市风格 | 选择不同城市风格 | P1 |

### 2.3 站点管理
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 添加站点 | 点击画布放置站点 | P0 |
| 移动站点 | 拖拽移动站点位置 | P0 |
| 删除站点 | 删除站点及相连轨道 | P0 |
| 站点类型 | 普通站/换乘站 | P1 |
| 站点命名 | 全局唯一名称 | P0 |

### 2.4 轨道建设
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 建设轨道 | 连接两个站点 | P0 |
| 删除轨道 | 删除选中轨道 | P0 |
| 轨道形状 | 直线/一次折线/两次折线 | P1 |
| 多轨道显示 | 同路段多轨道变细 | P2 |

### 2.5 终点站设置
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 智能识别 | 自动检测线路端点 | P1 |
| 手动选择 | 手动设置起点/终点 | P0 |
| 环线模式 | 设置为环线 | P1 |

### 2.6 列车模拟
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 开始模拟 | 列车开始运行 | P0 |
| 停止模拟 | 停止列车运行 | P0 |
| 沿轨道运行 | 100%沿轨道移动 | P0 |
| 往返运行 | 到达终点后返回 | P0 |
| 环线运行 | 持续循环运行 | P1 |

### 2.7 线路总览
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 站点列表 | 显示所有线路站点 | P1 |
| 高亮显示 | 单条线路高亮 | P1 |

### 2.8 任务系统
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 任务列表 | 6个渐进式任务 | P1 |
| 进度追踪 | 自动更新进度 | P1 |
| 奖励解锁 | 完成任务解锁奖励 | P1 |

### 2.9 成就系统
| 功能 | 描述 | 优先级 |
|------|------|--------|
| 成就列表 | 8个成就 | P1 |
| 解锁检测 | 自动检测解锁条件 | P1 |

## 3. 非功能需求

### 3.1 性能需求
- 页面加载时间 < 3秒
- 动画帧率 ≥ 30fps
- 支持最多100个站点

### 3.2 兼容性需求
- Windows 10/11
- macOS 10.15+
- 主流浏览器（Chrome、Firefox、Edge、Safari）

### 3.3 可用性需求
- 界面简洁直观
- 操作步骤最少化
- 错误提示清晰
- 支持撤销操作（未来）

### 3.4 安全性需求
- 本地数据存储
- 无网络传输
- 无敏感信息收集

## 4. 约束条件

### 4.1 数据约束
- 线路名称唯一
- 线路颜色唯一
- 站点名称全局唯一
- 同一线路两站点间轨道唯一

### 4.2 操作约束
- 模拟运行时禁止编辑
- 至少保留一条线路
- 删除站点时级联删除轨道

## 5. 验收标准

### 5.1 功能验收
- 所有P0功能正常工作
- 所有P1功能正常工作
- 无阻塞性Bug

### 5.2 性能验收
- 启动时间 < 5秒
- 操作响应 < 200ms
- 动画流畅无卡顿

### 5.3 文档验收
- README.md 完整
- 用户手册完整
- 开发文档完整
