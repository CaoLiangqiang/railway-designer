## 1. 快速入门

### 1.1 启动应用

**桌面应用**：
- 双击 `轨道线路图设计器_v1.0.0_便携版.exe` 即可运行

**浏览器**：
- 开发模式下访问 `http://localhost:5173/`

### 1.2 创建第一个项目

1. 点击左上角的 **"新建"** 按钮
2. 输入项目名称（如"我的地铁"）
3. 选择喜欢的城市风格（上海、北京等）
4. 点击 **"创建"**

### 1.3 创建第一条线路

1. 在左侧工具栏点击 **"线路"** 标签
2. 点击 **"添加线路"** 按钮
3. 输入线路名称（如"1号线"）
4. 选择线路颜色
5. 点击 **"添加"**

### 1.4 添加站点

1. 在左侧工具栏点击 **"站点"** 标签
2. 选择 **"普通站点"** 或 **"换乘站点"**
3. 在画布上点击想要放置站点的位置
4. 输入站点名称
5. 根据需要开启/关闭 **"自动连接至前一站点"**
6. 点击 **"添加"**

### 1.5 运行模拟

1. 点击顶部工具栏的 **"开始模拟"** 按钮
2. 观看列车在线路上运行
3. 点击 **"停止模拟"** 结束

### 2.2 工具栏

#### 线路标签
- **添加线路**：创建新线路
- **线路列表**：显示所有线路，可切换当前线路
- **设置终点站**：为当前线路设置起点和终点

#### 站点标签
- **普通站点**：圆形站点图标
- **换乘站点**：双圆环站点图标
- **建设轨道**：手动创建两个站点间的轨道
- **自动连接开关**：控制添加站点时是否自动连接前一站点
- **轨道形状**：选中轨道后可切换形状

#### 操作标签
- **选择工具**：选择和移动元素
- **平移工具**：拖拽移动画布
- **删除按钮**：删除选中的元素

### 2.3 任务面板

- **任务**：显示当前任务进度
- **成就**：显示已解锁和未解锁的成就
- **统计**：显示项目统计信息（站点数、线路数等）

## 3. 基础操作

### 3.1 创建项目

**步骤**：
1. 点击 **"新建"** 按钮
2. 输入项目名称
3. 选择城市风格
4. 点击 **"创建"**

**注意事项**：
- 项目名称不能为空
- 可以随时导出项目保存到本地

### 3.2 管理线路

#### 添加线路
1. 切换到 **"线路"** 标签
2. 点击 **"添加线路"**
3. 输入线路名称（不能与其他线路重复）
4. 选择颜色
5. 点击 **"添加"**

#### 切换线路
- 在线路列表中点击想要编辑的线路

#### 删除线路
- 点击线路右侧的 **"删除"** 按钮

#### 设置终点站
1. 点击线路的 **"设置终点站"** 按钮
2. 选择起点站
3. 选择终点站（环线则选择相同站点）
4. 勾选 **"环线"** 如果是环线
5. 点击 **"保存"**

### 3.3 添加站点

#### 普通站点
1. 切换到 **"站点"** 标签
2. 点击 **"普通站点"**
3. 在画布上点击放置位置
4. 输入站点名称（不能与其他站点重复）
5. 根据需要开启/关闭 **"自动连接至前一站点"**
6. 点击 **"添加"**

#### 换乘站点
1. 点击 **"换乘站点"**
2. 其他步骤与普通站点相同

**自动连接功能**：
- **开启**：新站点会自动与当前线路的最后一个站点连接
- **关闭**：创建孤立站点，不建立任何连接

### 3.4 建设轨道

1. 切换到 **"站点"** 标签
2. 点击 **"建设轨道"**
3. 选择 **起点站点**
4. 选择 **终点站点**
5. 选择 **所属线路**
6. 点击 **"建设"**

**注意事项**：
- 同一线路在两个站点间只能有一条轨道
- 如果站点不在所选线路中，会自动添加到该线路

### 3.5 编辑轨道

#### 选中轨道
1. 切换到 **"操作"** 标签
2. 点击 **"选择"** 工具
3. 点击想要编辑的轨道
4. 轨道会高亮显示（蓝色）

#### 切换形状
1. 选中轨道后，在 **"站点"** 标签的 **"轨道形状"** 区域
2. 点击想要的形状：
   - **直线**：直接连接两个站点
   - **一次折线**：在中间转折一次
   - **两次折线**：在中间形成两个转折

#### 删除轨道
- 选中轨道后，按 **Delete** 键
- 或在 **"操作"** 标签点击 **"删除"** 按钮

### 3.6 移动站点

1. 切换到 **"操作"** 标签
2. 点击 **"选择"** 工具
3. 点击想要移动的站点
4. 拖拽站点到新位置
5. 相连的轨道会自动跟随移动

### 3.7 删除站点

- 选中站点后，按 **Delete** 键
- 或在 **"操作"** 标签点击 **"删除"** 按钮

**注意**：删除站点时会同时删除所有与该站点相连的轨道。

### 3.8 画布操作

#### 平移画布
- 按住 **鼠标中键** 拖拽
- 或使用 **"平移"** 工具拖拽

#### 缩放画布
- 使用 **鼠标滚轮** 缩放

## 4. 高级功能

### 4.1 换乘站

换乘站是同时属于多条线路的站点。

**创建方法**：
1. 创建第一条线路的站点
2. 切换到第二条线路
3. 使用 **"建设轨道"** 功能
4. 选择已有的站点作为起点或终点
5. 该站点会自动成为换乘站

### 4.2 环线

环线是起点和终点相同的线路，列车会循环运行。

**设置方法**：
1. 在线路列表中点击 **"设置终点站"**
2. 选择起点站
3. 勾选 **"环线（起点和终点相同）"**
4. 点击 **"保存"**

### 4.3 项目导出/导入

#### 导出项目
1. 点击顶部 **"导出"** 按钮
2. 项目会保存为 JSON 文件下载到本地

#### 导入项目
1. 点击顶部 **"导入"** 按钮
2. 选择之前导出的 JSON 文件
3. 项目会加载到应用中

## 5. 任务与成就

### 5.1 任务系统

任务是引导用户学习功能的渐进式目标。

| 任务 | 描述 | 奖励 |
|------|------|------|
| 初识线路 | 创建包含3个站点的线路 | 解锁广州风格 |
| 设置终点站 | 为线路设置起点和终点站 | 解锁港铁风格 |
| 运行模拟 | 成功运行列车模拟 | - |
| 换乘枢纽 | 创建一个换乘站 | 解锁东京风格 |
| 环线设计 | 创建一条环线 | - |
| 多线路运营 | 创建3条线路 | - |

**查看任务**：在右侧任务面板的 **"任务"** 标签中查看当前任务进度。

### 5.2 成就系统

成就是对用户操作的额外奖励。

| 成就 | 描述 |
|------|------|
| 设计新手 | 创建第一个站点 |
| 轨道工程师 | 创建第一条线路 |
| 换乘专家 | 创建3个换乘站 |
| 环线大师 | 创建一条环线 |
| 多线路运营 | 创建3条线路 |
| 模拟运行 | 运行列车模拟 |
| 城市设计师 | 解锁所有城市风格 |
| 终点站规划师 | 为线路设置终点站 |

**查看成就**：在右侧任务面板的 **"成就"** 标签中查看已解锁和未解锁的成就。

## 7. 常见问题

### Q1: 为什么不能创建同名站点？

**A**: 站点名称在整个项目中必须唯一，这样便于管理和识别。如果尝试创建同名站点，会提示已存在。

### Q2: 为什么不能创建同名线路？

**A**: 线路名称在项目内必须唯一，避免混淆。

### Q3: 删除站点后，相连的轨道去哪了？

**A**: 删除站点时会自动删除所有与该站点相连的轨道，这是为了确保数据完整性，不会出现"悬空"轨道。

### Q4: 如何创建换乘站？

**A**: 使用 **"建设轨道"** 功能，选择已有站点作为起点或终点，该站点会自动成为换乘站。

### Q5: 轨道形状有哪些？如何切换？

**A**: 有三种形状：直线、一次折线、两次折线。选中轨道后，在 **"站点"** 标签的 **"轨道形状"** 区域点击想要的形状即可。

### Q6: 为什么有些轨道删除不了？

**A**: 请确保使用 **"选择"** 工具点击轨道线条本身（而不是站点），然后按 **Delete** 键删除。

### Q7: 如何保存我的设计？

**A**: 点击顶部 **"导出"** 按钮，项目会保存为 JSON 文件。之后可以使用 **"导入"** 功能加载。

### Q8: 自动连接功能有什么用？

**A**: 开启后，新创建的站点会自动与当前线路的最后一个站点连接。关闭则创建孤立站点，适合先规划站点位置再连接的场景。

### Q9: 如何解锁更多城市风格？

**A**: 完成任务可以解锁新的城市风格。在右侧任务面板查看当前任务。

### Q10: 列车为什么不运行？

**A**: 请检查：
1. 线路是否设置了终点站
2. 线路是否至少有两个站点
3. 是否点击了 **"开始模拟"** 按钮
