# 轨道线路图设计器 - 用户手册

## 版本: v1.1.0

## 快速入门

### 启动应用
双击 `轨道线路图设计器_v1.1.0_便携版.exe` 或已安装的应用图标即可启动。

### 创建第一个项目
1. 点击左侧工具栏的 **"新建"** 按钮
2. 输入项目名称，例如"我的地铁"
3. 选择喜欢的城市风格
4. 点击 **"创建"** 按钮

## 功能详解

### 一、项目管理

#### 1.1 新建项目
- 点击"新建"按钮
- 输入项目名称
- 选择城市风格（上海、北京、广州、港铁、东京）
- 点击创建

#### 1.2 导入项目
- 点击"打开"按钮
- 选择 JSON 文件 或 粘贴 JSON 数据
- 点击导入

#### 1.3 导出项目
- 点击"导出"按钮
- 自动下载 JSON 文件
- 可分享给他人导入使用

### 二、线路管理

#### 2.1 添加线路
1. 切换到 **"线路"** 标签页
2. 点击 **"添加线路"**
3. 输入线路名称（不能与已有线路重名）
4. 选择线路颜色（不能与已有线路颜色相同）
5. 点击添加

> **注意**: 线路名称和颜色在整个项目中必须唯一

#### 2.2 选择线路
- 在线路列表中点击线路卡片
- 选中的线路会显示蓝色边框

#### 2.3 删除线路
- 点击线路卡片右侧的 **×** 按钮
- 至少保留一条线路

#### 2.4 设置终点站
1. 点击选中线路的 **"设置终点站"** 按钮
2. 点击 **"自动识别终点站"** 自动检测
   - 或手动选择起点站和终点站
3. 可选择 **"环线"** 模式
4. 点击保存

### 三、站点管理

#### 3.1 添加站点
1. 切换到 **"站点"** 标签页
2. 选择站点类型：
   - **普通站**: 圆形站点
   - **换乘站**: 双圆站点，用于线路换乘
3. 在画布上点击放置站点
4. 输入站点名称（全局唯一）

#### 3.2 移动站点
1. 使用 **"选择"** 工具
2. 点击站点选中
3. 拖拽到新位置

#### 3.3 删除站点
1. 选中站点
2. 按 **Delete** 或 **Backspace** 键
3. 相连的轨道会自动删除

### 四、轨道建设

#### 4.1 建设轨道
1. 切换到 **"站点"** 标签页
2. 点击 **"建设轨道"** 按钮
3. 选择起点站点
4. 选择终点站点
5. 选择所属线路
6. 点击建设

#### 4.2 修改轨道形状
1. 使用选择工具点击轨道
2. 在 **"轨道形状"** 区域选择：
   - **直线**: 两点直接连接
   - **一次折线**: 一个拐点
   - **两次折线**: 两个拐点

#### 4.3 删除轨道
1. 选中轨道
2. 按 **Delete** 键

### 五、线路总览

#### 5.1 查看线路总览
1. 切换到 **"总览"** 标签页
2. 查看所有线路及其站点列表

#### 5.2 高亮显示线路
- 点击线路卡片
- 该线路高亮显示，其他线路变灰
- 再次点击取消高亮

### 六、列车模拟

#### 6.1 开始模拟
1. 确保已设置终点站
2. 点击 **"开始模拟"** 按钮
3. 观看列车沿轨道运行

#### 6.2 模拟行为
- **往返线**: 列车从起点到终点，再返回起点
- **环线**: 列车持续循环运行

#### 6.3 停止模拟
- 点击 **"停止模拟"** 按钮

> **注意**: 模拟运行时无法编辑站点和轨道

## 常见问题

### Q: 为什么无法添加线路？
A: 请确保线路名称和颜色与已有线路不同。

### Q: 为什么列车不运行？
A: 请确保已设置终点站，且线路有轨道连接。

### Q: 如何修改站点名称？
A: 目前不支持直接修改，可删除后重新添加。

### Q: 项目数据保存在哪里？
A: 数据保存在浏览器本地存储中，导出后可备份。

### Q: 模拟运行时为什么无法编辑？
A: 为防止误操作，模拟运行时禁止编辑。
